**Como atualizar:** edite o arquivo e republique passando a URL correspondente.
Antes de publicar, leia a versão que está no ar e construa a alteração sobre
ela — publicar sem ler é recusado, justamente para não descartar uma edição
feita de outro lugar.

**Não são fonte do produto.** São documentos: o que está no ar, o que está
aberto e por quê. A regra que vale para as telas vale para eles — número sem
medição não entra, e onde não houve medição fica travessão, nunca zero.
